# CS TA Website Project

## Overview
This project is a collaborative web development effort to create a comprehensive website for our Computer Science Teaching Assistant (TA) program. It serves as both a learning experience for TAs and students of various skill levels and a practical tool for showcasing our program.

## Features
- Home page with program overview
- Career Development pages
- Clubs information page
- Meet the Team pages
- Contributions pages 
- Student Projects pages
- And more!

## Project Documentation
For comprehensive documentation of the entire repository, including detailed explanations of each component and instructions on how to contribute, please see our [Contributors Guide](frontend/src/pages/contributors/WorkflowGuide.tsx).

## Tech Stack
- Frontend: React & TypeScript
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy 
- Styling: TailwindCSS


## Project Timeline and Development Phases


### Section 1: Interactive Learning Experience
The initial phase of this project served as an interactive lesson plan for Teaching Assistants, designed to:
- Teach modern web development practices
- Foster teamwork and collaboration skills
- Build professional portfolios and resumes
- Develop technical presentation abilities
- Create hands-on experience with real-world project management


### Section 2: React Migration and Sustainability
The next phase focused on modernization and long-term sustainability:
- Migrated the application to React for improved maintainability
- Implemented modern frontend practices
- Enhanced user experience and performance
- Created comprehensive documentation
- Established processes for year-to-year knowledge transfer
- Set up continuous improvement workflows

### Section 3: Full Stack Implementation
This phase focused on modernizing the application to a full stack application:
- Implemented a backend API for data management
- Implemented a database for data storage
- Implemented a content management system for easy content updates
- Implemented a user authentication system for secure access

## Project Goals
1. Create a valuable resource for the CS department
2. Provide real-world development experience for TAs and students
3. Establish a sustainable platform that can evolve with department needs
4. Build a showcase of student capabilities
5. Create a template for future collaborative projects
